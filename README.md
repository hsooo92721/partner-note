# PARTNER NOTE

사용하기: https://hsooo92721.github.io/partner-note/

매장 파트너를 위한 통합 업무 보조 **연구용 인터랙티브 프로토타입**입니다.

내품기 계산, 부재료 레시피, 음료 레시피, 매장 설정을 하단 메뉴에서 바로 엽니다.

## 실행

Node.js 22 이상 권장. 저장소 루트에서 실행하세요.

```sh
npm ci
npm run dev
```

표시된 로컬 URL을 브라우저에서 엽니다. 서버가 없는 앱이므로 계정·API 키가 필요하지 않습니다.

```sh
npm test
npm run build
npx vite preview --host 127.0.0.1
```

`dist/`에 정적 배포 파일이 생성됩니다. GitHub 저장소 업로드와 웹사이트 배포는 별개입니다.

## 사용 방법

- 내품기에서 품목명이나 약어를 검색합니다. 개봉·소분·제조 규칙은 한 품목 아래에 표시됩니다. 보관기준은 각 규칙에 표시하며, 출처와 특이사항은 펼쳐 볼 수 있습니다.
- 오늘 현재, 내일 오픈, 직접 지정 중 하나를 선택하면 마감일과 요일 숫자가 갱신됩니다. 매장 설정에는 요일별 영업시간과 공휴일·임시 변경일을 입력합니다.
- 부재료와 음료는 목록에서 펼쳐 봅니다. 등록된 음료의 HOT·ICED 절차와 사이즈별 수량을 단계별로 확인합니다.
- 데이터 관리에서 품목과 제조법을 입력하고 미리보기 후 저장합니다. 숨김, JSON 백업·복원, 같은 관리 화면에서 직전 저장 되돌리기를 지원합니다.

## 시연 계산 기준

- 시간형은 현재 모드에서 정시를 기준으로 계산합니다. 직접 지정, 매장 오픈 시각 또는 분 유지 규칙은 입력된 분을 유지합니다.
- 일수형과 개월형은 작업일 포함을 기본으로 사용합니다. 규칙에서 바꿀 수 있으며, 월말을 넘는 개월 계산은 대상 월 말일을 사용합니다.
- 영업일 예외는 요일 설정에 우선합니다. 다음 영업일 오픈 시간이 미입력 상태이면 계산 화면에서 설정을 안내합니다.
- 공식 기준 확인이 필요한 수치는 시연용입니다. 출처와 특이사항은 표의 오른쪽에서 확인합니다.

매장 설정과 데이터 편집 내용은 해당 브라우저에 저장됩니다. 로그인, 가입 승인, 역할별 권한, 공용 데이터 동기화와 관리자 감사 이력은 운영 버전 범위입니다. 제조법 자료가 없는 품목은 확인 중으로 표시합니다.
