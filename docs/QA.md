# 검수 결과

검수일: 2026-11-10 (Asia/Seoul). 로컬 Vite 서버를 실제 실행하고 내장 브라우저에서 확인했습니다.

## 자동 검사

- `npm test`: 11개 테스트 통과.
- `npm run build`: TypeScript 검사 및 Vite 프로덕션 빌드 성공.
- GitHub Actions: push/PR마다 같은 테스트와 빌드 실행.

범위: 시드 스키마/ID 관계, 음료명/마킹명/별칭 검색, 코르타도/더블샷 제한, 온도별 사이즈, 트렌타 전용 절차, 수량 매핑, 작업별 독립 규칙, 미등록 규칙, 시행 기간, 월말/평년/윤년/연말/자정/시간/기산일, 요일 설정, 잘못된 데이터 거부.

## 검수 한계

- 실제 iOS/Android 기기와 인쇄 하드웨어 검증은 하지 않았습니다.
- 실제 데이터 초기화는 브라우저에서 실행하지 않았습니다. 코드상 확인 대화상자 후 시드 복원입니다.
- 흐릿한 이미지 수치, 실제 시행일과 현행 공식 기준은 확인 대기입니다.
- 날짜 필드/서식의 동적 렌더링, 모든 필드의 전용 폼, 추가 기준표의 모든 품목 전사는 후속 확장 범위입니다.
